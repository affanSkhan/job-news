# JobNews

AI-assisted jobs, internships and opportunities discovery platform.

## Product direction
- Source-first listings with explicit freshness and application links
- SEO-first canonical detail pages with JobPosting JSON-LD
- AI for normalization, classification, deduplication and semantic matching — not invented facts
- Analytics and AdSense hooks via environment variables
- Database-backed ingestion and daily automation are the next production layer

## Research-backed choices
Google recommends JobPosting structured data on individual job pages and accurate freshness data, along with canonical URLs and sitemaps. AdSense requires original, useful content and a fully functioning, navigable site. Research on job platforms highlights information quality, usability, trust, and richer discovery approaches.
